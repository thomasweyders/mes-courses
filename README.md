# Mes courses - version mise a jour

Cette version integre les 6 recettes du dernier fichier Excel fourni :
- Chachouka
- Boulette haricot rouge
- Lasagne bolo
- Poisson mexicaine
- Lentilles caviar aubergine
- Mijote poisson olives

## Installation
1. Publier tous les fichiers ensemble sur un hebergement HTTPS, par exemple GitHub Pages.
2. Ouvrir l adresse dans Safari sur iPhone.
3. Choisir Partager, puis Sur l ecran d accueil.
4. Dans Recettes, completer les unites, absentes du fichier Excel source.
5. Dans Sauvegarde, exporter regulierement les donnees en JSON.

Le fichier Excel n est pas necessaire au fonctionnement de l application.

## Photos des recettes
Dans Recettes, choisir Modifier puis Choisir ou prendre une photo. Sur iPhone, il est possible d utiliser l appareil photo ou la phototheque. L image est reduite avant enregistrement et reste stockee localement. Elle est incluse dans les sauvegardes JSON exportees.
